# 🍰 Pastelería Mil Sabores

Proyecto web desarrollado para **Pastelería Mil Sabores**, una tienda virtual orientada a la visualización y compra de productos de pastelería.

El sistema permite navegar por un catálogo de productos, registrarse, iniciar sesión, agregar productos al carrito, modificar cantidades, realizar un proceso de checkout y administrar información básica del usuario.

---

## 📌 Descripción del proyecto

**Mil Sabores** corresponde a una aplicación web desarrollada utilizando tecnologías Front-End.

El proyecto busca representar el funcionamiento básico de una tienda online de pastelería, proporcionando una interfaz sencilla que permita al usuario:

- Navegar por diferentes secciones del sitio.
- Consultar productos disponibles.
- Filtrar productos según sus características.
- Registrarse en el sistema.
- Iniciar y cerrar sesión.
- Agregar productos al carrito.
- Modificar cantidades dentro del carrito.
- Eliminar productos.
- Calcular automáticamente subtotales y total de compra.
- Completar un proceso de checkout.
- Visualizar y editar información del perfil.
- Utilizar un formulario de contacto.
- Consultar preguntas frecuentes.
- Consultar contenido informativo de la pastelería.

---

## 🎯 Objetivo

Desarrollar una página web funcional para una pastelería utilizando **HTML, CSS y JavaScript**, aplicando conceptos de:

- Estructura semántica en HTML.
- Diseño y estilos mediante CSS.
- Diseño adaptable a distintos tamaños de pantalla.
- Manipulación del DOM mediante JavaScript.
- Eventos.
- Validación de formularios.
- Arreglos y objetos.
- Almacenamiento de información mediante LocalStorage.
- Componentes de Bootstrap.

---

## 🛠️ Tecnologías utilizadas

### HTML5

Utilizado para crear la estructura y contenido de las diferentes páginas del proyecto.

### CSS3

Utilizado para definir:

- Colores.
- Tipografías.
- Tamaños.
- Botones.
- Formularios.
- Distribución de elementos.
- Diseño responsive.
- Catálogo.
- Carrito.
- Perfil de usuario.

### JavaScript

Utilizado para implementar la lógica e interacción del sitio, incluyendo:

- Registro de usuarios.
- Inicio de sesión.
- Validaciones.
- Carrito de compras.
- Filtros del catálogo.
- Checkout.
- Perfil.
- Contacto.
- Manejo de LocalStorage.

### Bootstrap

Se utiliza Bootstrap para complementar el diseño e implementar algunos componentes visuales e interactivos del sitio.
